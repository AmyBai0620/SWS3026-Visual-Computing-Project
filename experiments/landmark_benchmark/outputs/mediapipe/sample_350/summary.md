# MediaPipe FER-2013 350 张小样本测试总结

## 1. 测试设置

- 模型：MediaPipe Face Mesh 0.10.21
- 样本：FER-2013 train 中每类 50 张，共 350 张
- 输入预处理：48×48 灰度图放大到 256×256
- 输出关键点：468 点
- `min_detection_confidence`：0.5
- 本轮使用默认设置，没有对失败样本使用 padding、CLAHE、降低阈值等补救措施

## 2. 总体结果

| 指标 | 结果 |
|---|---:|
| 总样本数 | 350 |
| 成功提取 | 317 |
| 提取成功率 | 90.57% |
| 失败样本 | 33 |
| 失败率 | 9.43% |
| 平均耗时 | 4.86 ms/张 |
| 中位数耗时 | 4.86 ms/张 |
| P95 耗时 | 6.06 ms/张 |
| 最大耗时 | 13.99 ms |
| 关键点数量 | 468 |

## 4. 结果分析

MediaPipe 在 FER-2013 低分辨率图片上整体可行。默认设置下，350 张中有 317 张成功返回关键点，成功率为 90.57%，单张平均耗时约 4.86 ms，速度足以支持后续全量特征提取和实时接入。

分类别看，Happy 的成功率最高，为 98%；Neutral 和 Surprise 均为 96%；Fear 为 92%。Angry、Sad 和 Disgust 相对较低，分别为 82%、84% 和 86%。

结合失败样本可视化，失败主要集中在大角度侧脸、脸部裁剪不完整、强遮挡、暗光、低对比度和极低分辨率图片。类别差异更可能来自各类别中困难样本比例不同，而不是 MediaPipe 对某一种表情本身存在明显偏好。

成功样本抽查中，大多数关键点能够较合理地贴合眼睛、眉毛、鼻子和嘴部；张嘴样本通常能表现出上下嘴唇分离，暂未发现严重的统一模板化现象。不过，当前自动几何有效率与提取成功率完全相同，说明自动有效性检查较宽松，不能替代人工质量检查。

## 5. 当前结论

- MediaPipe 通过了 350 张小样本可行性测试；
- 可以保留为全量候选模型；
- 目前不能仅凭这组结果直接确定它是最终最佳模型；
- 应等待 RTMPose-Face 和 FAN 在同一 manifest、默认设置下的结果，再统一比较；
- 第一轮横向比较应使用默认成功率 90.57%，暂不对 33 张失败样本进行补救；
- 三个模型都完成后，再统一设计失败样本补救实验，避免比较条件不一致。

## 6. 后续建议

1. 等待 RTMPose-Face 和 FAN 的 35/350 张结果；
2. 比较默认提取成功率、人工有效率、眼眉嘴贴合、张嘴响应、模板化风险和耗时；
3. 选出表现最好的 1～2 个模型跑全量；
4. 若 MediaPipe 入选，再单独对 33 张失败样本测试 padding、CLAHE、增大输入尺寸和降低检测阈值等补救措施；
5. 补救结果必须与默认结果分开记录；
6. 全量阶段保存图片路径、提取状态、关键点、标签、耗时和模型配置；
7. 最终在统一 train/validation/test 划分与相同分类器下比较 Accuracy、Macro F1、各类 Recall 和实时稳定性。
