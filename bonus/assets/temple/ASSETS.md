# Temple Run 素材清单

把素材按下面的**文件名**放进本文件夹(`bonus/assets/temple/`)。
`temple_run.py` 会自动检测:**有就用贴图,缺就回退到内置绘制版**,所以可以一个一个加,不用一次凑齐。

规则:
- 人物/障碍/金币 = **透明背景 PNG(RGBA)**
- 人物 = **背后视角**(背对镜头)
- 纹理 = **无缝可平铺**,俯视/正视,尽量正方形
- 尽量**同一套美术风格**

---

## 必需(影响最大)

| 文件名 | 内容 | 视角 | 建议尺寸 | 说明 |
|---|---|---|---|---|
| `player_run.png` | 主角奔跑 | 背后、全身 | ~400px 高 | 站立/跑步姿势,居中,脚在底 |
| `player_jump.png` | 主角跳起 | 背后、全身 | 同上,画布一致 | 双腿收起的跳跃姿势 |
| `player_slide.png` | 主角滑铲/下蹲 | 背后 | 同上,画布一致 | 低姿势,钻过头顶障碍用 |
| `coin.png` | 金币 | 正面 | ~128px | 单帧即可(我做旋转);见下方可选多帧 |
| `obstacle_barrier.png` | 单道障碍(换道躲) | 正/3-4 | ~300px | 石块/石像/巨石/断墙 |
| `obstacle_hurdle.png` | 低栏(跳过) | 正面 | ~300px 宽,矮 | 倒木/树根/矮石条/火坑 |
| `obstacle_overhang.png` | 高梁(下蹲钻过) | 正面 | ~400px 宽 | 悬梁/石拱/藤蔓/横幅,明显在头顶 |

## 强烈建议(质感)

| 文件名 | 内容 | 说明 |
|---|---|---|
| `floor_tile.png` | 地板纹理 | **无缝可平铺**,俯视,512×512(石砖/古道/木板) |
| `wall_tile.png` | 侧墙纹理 | **无缝可平铺**,512×512(神庙石墙/藤蔓) |

> 注:地板/侧墙纹理现在**已由代码程序化生成并滚动**(`temple_bg.py`),不放也能跑;放了真实无缝纹理可进一步提升质感(接口待接)。

## 远景天幕(可选,直接生效)

| 文件名 | 内容 | 说明 |
|---|---|---|
| `backdrop.png` / `backdrop.jpg`(或 `sky.png/jpg`) | 远景照片 | 放进 `assets/` 根目录即自动用作**地平线以上的天幕**。一张真实丛林/神庙/洞穴照片即可,**静态没问题**(远处本来不动,运动感由滚动地面负责)。不放则用渐变天空。 |

## 可选(锦上添花)

| 文件名 | 内容 | 说明 |
|---|---|---|
| `player_run_0.png` … `player_run_7.png` | 跑步循环帧 | 有的话我做流畅跑步动画(替代单张 player_run.png) |
| `coin_0.png` … `coin_7.png` | 金币旋转帧 | 有的话金币真旋转(替代单张 coin.png) |
